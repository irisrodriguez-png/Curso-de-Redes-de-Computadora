Diferencia entre switch y router


Aunque ambos son dispositivos de red, cumplen funciones diferentes.

Switch: conecta dispositivos dentro de una misma red local (LAN). Utiliza principalmente las direcciones MAC para identificar los equipos y enviar las tramas al puerto correspondiente.

Router: permite comunicar redes diferentes entre sí. Utiliza direcciones IP para determinar hacia dónde debe enviar los paquetes y normalmente sirve como punto de conexión entre la red local e Internet.

 

Ejemplo: en una empresa, el switch conecta las computadoras, impresoras y otros dispositivos de una oficina; mientras que el router permite que esa red se comunique con otras redes o tenga acceso a Internet.
